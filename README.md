# funpay-mcp

MCP-сервер для автоматизации работы с FunPay: анализ рынка, управление объявлениями, чат и заказы, профиль, отзывы.

## Стек

- Python 3.12+, `mcp[cli]`, `requests`, `beautifulsoup4`, `lxml`, `playwright`
- Точка входа: `funpay_mcp.server:main` (`src/funpay_mcp/server.py`)

## Возможности

- **Аналитика рынка**: парсинг категорий и лотов, отчёты по конкурентам (`market_research.py`)
- **Объявления**: создание/редактирование лотов, массовые операции (`mass_create.py`)
- **Чат и заказы**: чтение диалогов, статусы заказов
- **Профиль и отзывы**: данные аккаунта, работа с отзывами

## Установка

```bash
pip install -e .
playwright install
```

## Авторизация

Нужны куки сессии FunPay (файл `cookies.txt` в корне, в репозиторий не входит).
Получить можно через `src/funpay_mcp/browser_login.py` (Playwright-логин) или экспорт из браузера.

## Запуск

```bash
funpay-mcp
# или
python -m funpay_mcp
```

## Дисклеймер

Автоматизация действий на FunPay может нарушать правила площадки. Используйте на свой риск.
